Mario vs. Luigi is a remake of the multiplayer mode from New Super Mario Bros. on the Nintendo DS. You can play online with 2 to 10 players.

You do not need a ROM or an emulator. The download already has everything you need to play.

> **FYI: Play in your browser.** You can also [play Mario vs. Luigi on itch.io](https://ipodtouch0218.itch.io/nsmb-mariovsluigi) without installing it. The browser version supports online multiplayer.

## Before you start

- A Windows PC
- A controller
- An internet connection if you want to play online

## How to install it on Windows

1. Open the official [Mario vs. Luigi releases page](https://github.com/ipodtouch0218/NSMB-MarioVsLuigi/releases/latest).
2. Click **Assets** under the newest release.
3. Download the **Win64** version.
4. Unzip the folder after it finishes downloading.
5. Connect your controller and open the game's `.exe` file.

The game should pick up your controller on its own. You should not need to change any controller settings.

To play online, click **Play Game** on the main menu. You can join a room or make your own.

## Controls

| Action | Gamepad control |
| --- | --- |
| Move | Left stick or D-pad |
| Jump | A or B |
| Sprint | Hold X or Y |
| Use power-up | RB or RT |
| Use reserve item | LB or LT |
| Show scoreboard | Select |
| Pause | Start |

You can change the controls in the game settings if you want to.

## Playing on an AYN Thor

I also got the game working on an AYN Thor with GameHub Lite.

1. Download and unzip the same **Win64** version from the steps above.
2. Add the game's `.exe` file to GameHub Lite.
3. Open the game through GameHub Lite.

The Thor controls were picked up automatically and the game worked without a ROM.

This is still the Windows version of the game. There is no Android version in this download, so it may work differently on other Android handhelds.
