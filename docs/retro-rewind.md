Retro Rewind adds a lot of tracks to Mario Kart Wii, including tracks from older and newer Mario Kart games. You can also play online.

This guide uses WheelWizard and WiiCompiled. You do not need to set up Dolphin for these steps.

## Before you start

- A Windows PC
- A controller
- An internet connection
- Your own PAL Mario Kart Wii game file

PAL is the European version of Mario Kart Wii. WiiCompiled needs this version. Use a clean game file that you made from your own disc.

## Install WheelWizard

1. Open the official [WheelWizard releases page](https://github.com/TeamWheelWizard/WheelWizard/releases/latest).
2. Download the Windows version from the newest release.
3. Open WheelWizard after it finishes downloading.

WheelWizard will let you know when a new update is ready, so you do not need to keep checking the releases page.

## Set up Retro Rewind

1. Open **Settings** in WheelWizard.
2. Go to **Other** and turn on **Enable WiiCompiled**.
3. Go back to **Settings** and choose your Mario Kart Wii game file.
4. Open the **My Miis** tab and make your Mii. WheelWizard will use it for your Mario Kart license.
5. Go back to **Home** and click **Install**.
6. Wait for WheelWizard to finish setting everything up.
7. Choose **Retro Rewind** on the Home page and click **Play**.

WheelWizard downloads Retro Rewind and builds the game on your PC. The first install can take a while, so let it finish before closing WheelWizard.

## Game file help

WheelWizard can use game files such as ISO, WBFS and RVZ. The WiiCompiled setup only works with a clean PAL copy of Mario Kart Wii.

This guide does not include a download for Mario Kart Wii. You need to make the game file from your own disc.
